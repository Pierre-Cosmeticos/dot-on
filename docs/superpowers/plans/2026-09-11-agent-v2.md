# DOT-ON Agent v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reescrever o agente desktop em módulos testáveis, cobrindo os 13 itens da spec.

**Architecture:** Pacote `app/agent/doton/` com núcleo puro (`jornada.py`, `alertas.py`, `fila.py`) sem Qt, cliente HTTP isolado e UI PyQt5 que só orquestra timers/sinais. `agent.py` vira entrypoint.

**Tech Stack:** Python 3.10+, PyQt5 5.15, requests, pytest, PyInstaller (onefile).

**Spec:** `docs/superpowers/specs/2026-09-11-agent-v2-design.md`

## Global Constraints

- Nunca registrar saída automaticamente nem bloquear tela.
- Tempo trabalhado sempre calculado a partir das batidas do servidor + relógio do servidor (`agora`).
- Dados persistentes em `%APPDATA%\DOT-ON` quando congelado; `dot-on.ini` ao lado do .exe tem prioridade de `api_url`.
- Batida offline entra na fila com `client_uid` e é reenviada; servidor é idempotente.
- Versão `2.0.0`, manifesto `obrigatoria: true`.
- Sem commit até o usuário pedir.
